# Labs - Module 01: Fundamentals

| Lab | Topic | Title | Track | Level | Time | Description |
|-----|-------|-------|-------|-------|------|-------------|
| 01 | Setup | [Install and Set Up Claude Code](01-setup-claude/readme.md) | Required | Beginner | 30m | Install Claude Code CLI, authenticate, and explore it through the VS Code extension. |
| 02 | First App | [Build a Task Tracking REST API](02-hello-claude/readme.md) | Core | Beginner | 40m | Build a Python REST API for task management using Claude Code. Every step is prompt-driven: you provide the prompt, Claude does the work. |
| 03 | Prompting | [Apply Prompting Techniques](lab-03-prompting-techniques-and-plugins.md) | Optional | Intermediate | 50m | Apply five prompting techniques to your harness: statefile maintenance, anchors, @-mentions, few-shot examples, and slash-command promotion. |

**Core** is the one lab that teaches this module's central capability; run it if you run nothing else. **Optional** labs go deeper, cover a second tool, or need an account you may not have. **Required** is a prerequisite rather than a teaching lab; nothing else in the course works until Claude Code is installed and authenticated. **Level** rates the lab itself: Beginner needs no prior Claude Code experience, Intermediate assumes you have configured a harness before, Advanced assumes you are comfortable with hooks, subagents, or headless scripting.

Core path: 1h 10m. All labs: 2h.

Lab 03 has a starter already in the repo at `03-prompting/users-api/` and a finished counterpart beside it at `03-prompting/users-api-solution/`. The starter ships pristine (no dependencies, no build output); you install inside it and build the lab's artifacts there, and the solution is the completed reference when you want to compare.
