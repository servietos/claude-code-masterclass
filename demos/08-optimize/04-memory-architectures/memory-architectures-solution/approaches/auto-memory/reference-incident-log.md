Source records for anything a memory summarises:

- `corpus/incidents.md`: INC-001 to INC-003 with severity, duration, root cause, fix and owner
- `corpus/decisions.md`: ADR-001 to ADR-003 with rationale and consequence
- `corpus/team-notes.md`: sprint membership, in-flight work and active risks

Read the record rather than the memory whenever the exact wording, a date, or a field the memory dropped is what the answer turns on.
