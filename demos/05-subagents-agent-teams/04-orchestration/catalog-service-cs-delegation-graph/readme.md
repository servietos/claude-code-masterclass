# Catalog Service - App Modernization

A .NET 10 ASP.NET Core catalog API backed by EF Core and the seeded `food.db` SQLite file. `FoodController` serves `/food`, and it is the starter the demos in this topic extend.

This copy is the finished result of [`demo-workflow-graph.md`](../demo-workflow-graph.md): two schema-validated nodes fanned out by `parallel()`, then a three-lens verification panel whose vote was counted in the script body.
