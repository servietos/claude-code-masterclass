# Claim Monthly API Credits

Max and Team plans include monthly credits for the Claude API, Managed Agents and the Agent SDK, which covers every demo and lab in this module. Claude Code itself is not covered.

| Plan | Monthly credit |
|---|---|
| Max 5x | $100 |
| Max 20x | $200 |
| Team | $20 per Standard seat, $100 per Premium seat, pooled up to $500 |

Unused credit expires at the end of each billing cycle.

## Max

You need a Max plan that has been active for at least 7 days, and the Owner, Admin or Billing role in the Console organization you link.

1. Sign in to [claude.ai](https://claude.ai) in a web browser and open **Settings > Billing**.
2. In the **API credits** section, select the Console organization that should receive the credits, or create one there.
3. Accept the program terms by linking. The link is permanent: only [support](https://support.claude.com/en/articles/9015913-how-to-get-support) can move it to another organization.
4. In the Console, open the [Billing page](https://platform.claude.com/settings/billing) and check **Promotional credits** for the amount and expiry date.
5. On the [API keys page](https://platform.claude.com/settings/keys), create a key in the linked organization and put it in `.env` in this folder.

## Team

You need a Team plan that has been active for at least 7 days, the Primary Owner or Owner role on the plan, and the Owner, Admin or Billing role in the Console organization you link.

1. Sign in to [claude.ai](https://claude.ai) in a web browser and open **Organization settings > Billing**.
2. In the **API credits** section, select the Console organization that should receive the credits, or create one there.
3. Accept the program terms by linking. The link is permanent: only [support](https://support.claude.com/en/articles/9015913-how-to-get-support) can move it to another organization.
4. In the Console, open the [Billing page](https://platform.claude.com/settings/billing) and check **Promotional credits** for the amount and expiry date.
5. On the [API keys page](https://platform.claude.com/settings/keys), create a key in the linked organization and put it in `.env` in this folder.

The credit follows the seats on the plan at the start of each billing month, so a seat added today counts from next month.

If the **API credits** section is missing in either plan, the plan is not eligible yet; [contact support](https://support.claude.com/en/articles/9015913-how-to-get-support) if it should be.

Source: [API credits for Max and Team plans](https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers)
